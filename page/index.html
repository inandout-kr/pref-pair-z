현재

  • z = (오늘 비율 − 이동평균) ÷ 이동σ
  • 행 클릭 시 해당 페어 차트 이동
  • 열 제목 클릭 시 오름차순 → 내림차순 → 기본 순서로 정렬

이동 구간 짧을수록 z가 자주, 크게 움직이고 신호 잦아짐. 구간이 길수록 평균이 천천히 따라오므로 추세 타는 페어는 한쪽에 오래 머묾. 위 칸 음영은 이동평균 주변의 σ 범위, 아래 칸 가로선은 z-score 기준선. 배당락일에는 본주와 우선주의 배당 차이만큼 비율이 움직임.
